# Ariva-Store

A sideloading helper app for iOS — install IPA files over a VPN connection.

**Author:** Eksemekse-dev

> This app was created with the help of AI. It is not intended for piracy and does not support it.

## Build

Push to `main` — GitHub Actions will build an unsigned `.ipa` artifact.
